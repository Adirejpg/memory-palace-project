# Noun Cards

A tiny offline web app for memory palace practice: swipe through random nouns, recall them in order, and track your stats.

- Works fully offline after the first launch (service worker cache)
- All sessions and stats are stored only on your device
- No dependencies, no build step

## Install on iPhone
1. Open the GitHub Pages URL in Safari
2. Share → Add to Home Screen
3. Launch it once from the home screen while online — after that it works offline
